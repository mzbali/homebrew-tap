# ClipVee Homebrew tap

[ClipVee](https://github.com/mzbali/ClipVee) is Windows-style clipboard history for the Mac. Press ⌘⇧V, pick a card, and it's pasted.

```sh
brew install --cask mzbali/tap/clipvee
```

To update, run `brew upgrade --cask mzbali/tap/clipvee`. To have a plain `brew upgrade` include ClipVee, trust the tap once with `brew trust mzbali/tap`.

ClipVee isn't notarised by Apple, so the first time you open it, go to System Settings → Privacy & Security and click **Open Anyway**. Then turn ClipVee on under Privacy & Security → Accessibility so it can paste for you.
